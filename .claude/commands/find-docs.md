Search Paperless for: $ARGUMENTS

Use `mcp__paperless__search_documents` to find relevant documents. Read their content and synthesise a useful answer.

Steps:
1. Run a search with the query as the `query` parameter (limit 10)
2. If results look relevant, read the content field of the top matches
3. Synthesise the findings into a clear answer — what documents exist, what they say, any key facts/dates/amounts
4. List the documents found with title, date, and document ID for reference

If no results, try a broader or alternative search term before giving up.
