Find and summarise all Paperless documents related to: $ARGUMENTS

Steps:
1. Search for relevant documents using `mcp__paperless__search_documents` — try 2–3 searches with different terms if needed (limit 20 per search)
2. Deduplicate results by document ID
3. Read the content of each relevant document
4. Build a structured summary organised by sub-topic or chronology:
   - Group related documents together
   - Highlight key facts, dates, amounts, and parties
   - Note any gaps or missing documents that would be expected
5. List all source documents at the end (title, date, ID)

Be thorough — this is for building a complete picture, not a quick answer.
